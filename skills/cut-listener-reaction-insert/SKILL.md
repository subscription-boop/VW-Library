# cut-listener-reaction-insert

> Library technique (category: `cut`). Shared rules: [CONTRACT](../../../library/CONTRACT.md). To apply this to a video, follow [QUICK-CREATE](../../../library/QUICK-CREATE.md) (full rules: [EXECUTION](../../../library/EXECUTION.md)). The name is an identifier only: read this document for behavior.
> Execution part only. Analysis notes (observed measurements, history): [ANALYSIS.md](ANALYSIS.md) - open only when a decision needs them.

## Observable behavior
While the guest says "…won't make sense to anyone else", the picture cuts to the host laughing for ~0.9 s, then back to the guest. Audio and the caption track run on uninterrupted.

## Intended effect
Adds social proof and rhythm; hides a join in the speaker's audio.

## Defining characteristics
- Listener shot, ≈ 0.6–1 s. [Rule]
- Speaker audio and captions continue across. [Fixed]
- On a funny or striking line. [Rule]

## When to use
- Triggers: podcast/interview clips with a listener camera.
- Avoid when: solo talking heads.

## Relationships
- Part of `cut-rhythm-phrase-shots`-style variety for interview material.

## Adaptation
- Prefer a genuine reaction from the same moment.

## Key numbers
- All values are stated above; the per-source table is in ANALYSIS.md.

## Success criteria
- The reaction feels real and short.
